🇧🇷 Português:
Este repositório reúne a implementação de duas versões do Jogo da Velha desenvolvidas em Portugol (VisualG) — o formato tradicional e o Super Jogo da Velha (composto por um tabuleiro principal e nove subtabuleiros) — com o objetivo de aplicar na prática conceitos de lógica de programação, manipulação de vetores, validação de entradas e modularização de código por meio de procedimentos.
🇺🇸 English:
This repository brings together the implementation of two versions of Tic-Tac-Toe developed in Portugol (VisualG)—the traditional format and Super Tic-Tac-Toe (composed of one main board and nine sub-boards)—aimed at applying programming logic, array manipulation, input validation, and code modularization through procedures in practice.
